# History

This folder holds long-form historical context: milestone closure
notes, repository-evolution narratives, and after-action write-ups
that are too long to live in `docs/STATE.md` but worth preserving
for future agents.

## When to add a history doc

- after a milestone closes, as a readable summary of what shipped
  and what changed
- when the repository takes a meaningful directional shift (pivot,
  rewrite, major rescope)
- when a reader years later would want the "story" behind a set of
  decisions, not just the individual decision records

## What belongs elsewhere

- current state → `docs/STATE.md`
- durable rules → `docs/decisions/`
- active work → `docs/plans/`
- shipped plans → `docs/plans/archive/`

## Shape

Free-form. Prefer chronological structure with concrete links to
commits, PRs, plan archives, and decision records. Short is fine.
